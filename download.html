SSS, ohne EXE.

SSS besteht aus einer zentralen Python-Hauptdatei und einem übersichtlichen Datenordner. SSS 3.0 beschleunigt die Dateiprüfung mit einem Cache für unveränderte Dateien. Updates werden erst nach ausdrücklicher Zustimmung installiert. Keine EXE und keine BAT-Datei.

SSS für Windows herunterladen (.ZIP)Repository öffnen

Die App-Hauptdatei heißt sss_main.py. Unterstützende Dateien, Versionsinformationen, Abhängigkeiten und Assets liegen im Ordner SSS_Data. Python 3.11+ muss installiert sein.

Wartung & Wiederherstellung

SSS-Verwaltungstool

Eine eigenständige Python-Datei für den Fall, dass SSS nicht mehr startet oder repariert werden muss. Sie kann die Installation prüfen, die Programmdateien reparieren, die neueste Version installieren oder SSS vollständig entfernen. Deine Einstellungen und Quarantäne bleiben bei Reparatur und Update erhalten.

SSS-Manager.py herunterladen

Benötigt Python 3.11 oder neuer. Unter Windows mit Python öffnen. Der Manager benötigt keine zusätzlichen Python-Pakete.

Starten

  1. ZIP entpacken in einen eigenen Ordner.
  2. Im SSS-Ordner ein Terminal öffnen und einmalig py -3 -m pip install -r SSS_Data\\requirements.txt ausführen.
  3. Danach die Hauptdatei mit py -3 sss_main.py starten. Du kannst auch die Python-Datei direkt mit Python öffnen.
  4. Beim ersten Start den Einrichtungsdialog abschließen.
  5. Updates können in SSS über Updates geprüft und installiert werden. Wenn SSS nicht mehr startet, kann das separate Verwaltungsprogramm die Installation reparieren oder aktualisieren.

Was steckt drin?

  • Lokale Datei-Prüfung mit SHA-256
  • Quarantäne mit Bestätigung und Wiederherstellung
  • Optionale Ollama-KI-Erklärungen, lokal auf dem Gerät
  • Update-Prüfung mit ausdrücklicher Bestätigung vor dem Download und der Installation
  • Rotierende Ereignisprotokolle mit Zeitstempeln, Scan-Ergebnissen, Risiko-Hinweisen, Quarantäne- und Update-Aktionen
  • Logs, Einstellungen und ein harmloser Demo-Testordner mit Beispieldateien

SSS ist ein Prototyp und kein zertifizierter Virenschutz. Ergebnisse sind unvollständig und können Fehlalarme enthalten.
